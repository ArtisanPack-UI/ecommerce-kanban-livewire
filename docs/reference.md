# Reference

Lookup material for the board: the hooks it fires and the events its components exchange, its Artisan commands, its configuration keys, its components, and the ability each screen and action checks.

- [Hooks](reference/hooks.md): every filter and action the board applies, the Livewire events its components exchange, and the engine hooks that apply on the board.
- [Artisan commands](reference/commands.md): `ecommerce-kanban:install` and the engine commands a store uses with the board.
- [Configuration](installation/configuration.md): every key in `config/artisanpack/ecommerce-kanban-livewire.php`.
- [Components](extending/embedding-components.md#components): the Livewire components, their props, and the Blade components the board is built from.
- [Authorization](advanced/authorization.md): the engine ability behind each screen and action.
- [Routes](installation.md#routes): every board path and route name.
